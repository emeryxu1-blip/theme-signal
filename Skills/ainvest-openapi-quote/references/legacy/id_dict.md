# 1. 指标属性定义和说明



## 1.1. attr定义

用于描述指标id，比如指标周期（time_period）， 非必需



### 1.1.1. 请求attr

|             |                                                              |      |                                                              |                                                              |
| ----------- | ------------------------------------------------------------ | ---- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| time_period | 数据的统计周期，常用于行情相关数据，比如1分钟、5分钟、1日等  | 否   | min_* – 表示分钟，比如min_5表示5分钟day_* *–* 表示***日，比如day_1表示1日week_* - 标识*周，比如week_1标识1周month_* *– 表示月*，比如month_3表示3月year_* *– 表示年*，比如year_1表示1年注意：day_*/month_*/year_*的时候，trade_class只有intraday，因为业务上没有盘前盘后的日线 | "time_period":"min_5" 日以下周期，如1小时，用 min_604小时，用 min_240 |

### 1.1.2. 响应attr

|             |                                                              |      |                                                              |                                                              |
| ----------- | ------------------------------------------------------------ | ---- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| value_type  | 数据的分类，比如日期、比率等                                 | 否   | date – 日期，格式为 yyyy-mm-dd，交易所时区ratio – 百分比类型，并且对应的value是乘以100的，比如涨幅是5%，给的value就是5ratio2 – 比例类型，但值是否*100等需要根据unit来确定。unit=x100 表示后端已经乘了100，unit=x1000 表示后端已经乘了1000；如果unit不是x*则表示后端没有乘，给的是原始值，需要客户端自己x100 + % 展示比例类型price – 价格，比如最新价、最高价等，客户端按价格精度的规范展示 | "value_type":"date"                                          |
